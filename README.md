# Auspify Technologies - Task 3: Inventory Management System

A full-stack Inventory Management System built as part of the Auspify Technologies Software Development Internship.

## Tech Stack
- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js, TypeScript
- **Database:** MongoDB (Mongoose)

## Features
- Inventory Tracking & Stock Updates (+ / - Stock)
- Real-time Reports Dashboard (Total Items, Total Value, Low/Out of Stock)
- Search & Filter by Category
- Add & Delete Items
- Data Accuracy (Business logic prevents negative stock)

## How to Run

### Backend
```bash
cd backend
npm install
npm run dev
